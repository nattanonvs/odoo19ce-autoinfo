🏷️ ส่วนที่ 13 · ทรัพย์สิน (ยืม/จำหน่าย)

ส่วนนี้ครอบคลุมการดูแลทรัพย์สินและเครื่องมืออุปกรณ์ขององค์กร ตั้งแต่การยืม-คืนเครื่องมือ/อุปกรณ์ระหว่างพนักงาน ไปจนถึงการจำหน่าย/ตัดจำหน่ายทรัพย์สินถาวรพร้อมสร้างรายการบัญชีโดยอัตโนมัติ โมดูลทั้งสองนี้ทำงานต่อยอดบนมาตรฐานเดิม (Maintenance และ OCA Account Asset Management) โดยไม่แก้ไขโค้ดหลักของ Odoo

สารบัญส่วนนี้

  1. od19_asset_disposal — การจำหน่าย/ตัดจำหน่ายทรัพย์สิน
  2. od19_asset_loan — การยืม-คืนเครื่องมือ/อุปกรณ์

⬅️ ส่วนนี้รับต่อมาจาก handoff · in

ส่วนที่ 6 · การจัดซื้อ→ ส่วนที่ 8 · บุคคลฯ→ ส่วนนี้ (ส่วนที่ 13)

รับทรัพย์สิน/เครื่องมือที่ซื้อมา หรือมอบให้พนักงานยืมใช้งาน — ขึ้นทะเบียนอุปกรณ์และผูกกับทรัพย์สินทางบัญชีก่อนปล่อยยืม

➡️ ส่วนนี้ส่งต่อไปยัง handoff · out

ส่วนนี้ (ส่วนที่ 13)→ ส่วนที่ 3 · บัญชี (ค่าเสื่อม/ตัดจำหน่าย)→ ส่วนที่ 7 · มูลค่าสินค้า/ทรัพย์สิน

การจำหน่าย/ตัดจำหน่ายต้องบันทึกบัญชีให้ถูกต้อง — ตรวจยอดค่าเสื่อมสะสมและมูลค่าคงเหลือก่อนกด Dispose

od19_asset_disposal การจำหน่าย/ตัดจำหน่ายทรัพย์สิน (Asset Disposal)

โมดูล od19_asset_disposal เพิ่ม ขั้นตอนการจำหน่ายทรัพย์สิน ให้กับทรัพย์สินที่ดูแลด้วย OCA account_asset_management เมื่อจำหน่าย ระบบจะ (1) ยกเลิกรายการค่าเสื่อมที่ยังเป็นแบบร่าง (2) สร้างรายการบัญชีจำหน่าย (เดบิตค่าเสื่อมสะสม / เครดิตต้นทุนทรัพย์สิน / เดบิตบัญชีมูลค่าคงเหลือเพื่อปรับยอดให้สมดุล) และ (3) เปลี่ยนสถานะทรัพย์สินเป็น Disposed พร้อมบันทึกวันที่จำหน่าย ทั้งยังมีปุ่ม Revert Disposal ย้อนการจำหน่าย และงานตั้งเวลา (Cron) คำนวณค่าเสื่อมแบบปลอดภัย

เมนูและตำแหน่งใช้งาน

โมดูลนี้ไม่ได้สร้างเมนูใหม่ แต่จะเพิ่มปุ่มและแท็บในการ์ดทรัพย์สิน (โมเดล account.asset) ของโมดูลจัดการทรัพย์สินเดิม ผู้ใช้ที่มีสิทธิ์จึงเข้าไปที่หน้าจอทรัพย์สินแล้วใช้ปุ่มที่แถบด้านบนของฟอร์ม

  • บัญชี (Accounting) › ทรัพย์สิน (Assets) — เปิดการ์ดทรัพย์สินที่ต้องการจำหน่าย
  • ปุ่มบนแถบสถานะ (Header): Dispose และ Revert Disposal
  • แท็บ Disposal ในฟอร์ม เก็บข้อมูลวันที่จำหน่าย เหตุผล รายการบัญชี และเอกสารเชื่อมโยง

ขั้นตอนการจำหน่ายทรัพย์สิน

  1. เตรียมข้อมูลบัญชีให้ครบ — ตรวจว่าโปรไฟล์ทรัพย์สิน (profile_id) กำหนด บัญชีมูลค่าคงเหลือ (Residual Value Account) ไว้แล้ว มิฉะนั้นระบบจะไม่ยอมให้จำหน่าย
  2. เปิดการ์ดทรัพย์สินที่ต้องการจำหน่าย — ทรัพย์สินต้องอยู่ในสถานะ Running หรือ Close เท่านั้น
  3. กดปุ่ม Dispose — ปรากฏเฉพาะผู้ใช้กลุ่มผู้จัดการบัญชี และจะซ่อนเมื่อสถานะไม่ใช่ Running/Close
  4. ระบบยกเลิกรายการค่าเสื่อมร่าง — รายการค่าเสื่อม (depreciation_line_ids ประเภท depreciate) ที่ยังเป็น Draft จะถูกยกเลิกให้ก่อน
  5. ระบบสร้างรายการบัญชีจำหน่ายและลงบัญชีทันที — เดบิตค่าเสื่อมสะสม (มูลค่าที่ตัดแล้ว) / เครดิตบัญชีต้นทุนทรัพย์สิน / เดบิตบัญชีมูลค่าคงเหลือ (ปรับให้ยอดเดบิต = เครดิต)
  6. บันทึกสถานะและวันที่ — สถานะเปลี่ยนเป็น Disposed วันที่จำหน่ายถูกบันทึกอัตโนมัติ และลิงก์ไปยังรายการบัญชีจำหน่าย
  7. ตรวจสอบรายการบัญชี — ระบบเปิดหน้ารายการบัญชีจำหน่ายที่สร้างขึ้นให้ตรวจทันที
Running / Close → กด Dispose → ยกเลิกร่างค่าเสื่อม → สร้าง + ลงบัญชีรายการจำหน่าย → Disposed

การย้อนการจำหน่าย (Revert Disposal)

  1. เปิดการ์ดทรัพย์สินที่สถานะ Disposed — ปุ่มนี้จะปรากฏเฉพาะเมื่อสถานะเป็น Disposed
  2. กดปุ่ม Revert Disposal — ระบบกลับรายการบัญชีจำหน่าย (พร้อมยกเลิกรายการเดิม) และล้างวันที่จำหน่าย
  3. ทรัพย์สินกลับสู่สถานะ Running — สถานะเปลี่ยนเป็น Running และระบบเปิดหน้ารายการกลับรายการให้ตรวจสอบ

สถานะของทรัพย์สิน (State)

สถานะความหมาย

สิทธิ์การใช้งาน

  • ปุ่ม Dispose และ Revert Disposal จำกัดเฉพาะกลุ่ม account.group_account_manager (ผู้จัดการบัญชี)
  • การยกเลิกรายการบัญชี/กลับรายการทำผ่านบริบท allow_asset=True ของ OCA เพื่อไม่ให้เกิดข้อผิดพลาดการป้องกันทรัพย์สิน
ข้อควรระวัง: การจำหน่ายจะลงบัญชีรายการทันที (post) และยกเลิกรายการค่าเสื่อมร่างทั้งหมด ควรตรวจสอบยอดมูลค่าที่ตัดแล้วและมูลค่าคงเหลือก่อนกด Dispose ทุกครั้ง
เคล็ดลับ: ระบบมีงานตั้งเวลา Safe Depreciation ที่คำนวณค่าเสื่อมรายตัวใน savepoint ถ้าทรัพย์สินตัวใดผิดพลาดจะถูกบันทึกใน log โดยไม่ทำให้งานทั้งหมดล้มเหลว — ช่วยให้ค่าเสื่อมของทรัพย์สินรายอื่นยังคงคำนวณได้

od19_asset_loan การยืม-คืนเครื่องมือ/อุปกรณ์ (Asset Loan)

โมดูล od19_asset_loan เพิ่มระบบทะเบียนการยืม-คืนเครื่องมือและอุปกรณ์ภายในองค์กร (เช่น โน้ตบุ๊ก เครื่องมือวัด ของใช้ประจำแผนก) โดยผูกกับทะเบียนอุปกรณ์บำรุงรักษา (maintenance.equipment) และสามารถเชื่อมกับทรัพย์สินทางบัญชี (account.asset) เพื่อการคิดค่าเสื่อม ระบบออกรหัสใบยืมอัตโนมัติ ติดตามวันครบกำหนด ตรวจการยืมซ้ำ และแจ้งเตือนหลายช่องทางผ่านโมดูลแจ้งเตือนกลาง

เมนูและตำแหน่งใช้งาน

  • การบำรุงรักษา (Maintenance) › การตั้งค่า (Configuration) › Asset Loan › Loans — จัดการใบยืม-คืนทั้งหมด
  • ในหน้าจออุปกรณ์ (Equipment) มีปุ่มสถิติ Loans เปิดดูใบยืมของอุปกรณ์ชิ้นนั้น และฟิลด์ยืมถูกเพิ่มในฟอร์มอุปกรณ์

ขั้นตอนการยืม-คืน

  1. สร้างใบยืมใหม่ (Draft) — เลือก ผู้ยืม, วันที่ยืม, วันครบกำหนดคืน (และเหตุผล/บันทึกได้) ระบบออกรหัส AL/ปี/เลขรัน ให้อัตโนมัติ
  2. เพิ่มรายการอุปกรณ์ — ในแท็บ Equipment เพิ่มบรรทัด ระบุอุปกรณ์และจำนวน (ต้องมีอย่างน้อย 1 รายการก่อนยืนยัน)
  3. กดปุ่ม Confirm — สถานะเปลี่ยนเป็น Borrowed และรายการทุกบรรทัดเปลี่ยนตามไปด้วย
  4. เมื่อคืนของ กดปุ่ม Return — สถานะเป็น Returned บันทึกวันคืนจริง และตั้งจำนวนคืนเท่ากับจำนวนที่ยืมในทุกบรรทัด
  5. กรณีของหาย กดปุ่ม Mark Lost — สถานะเป็น Lost พร้อมปรับสถานะรายการทั้งหมด
  6. พิมพ์ใบยืม (ถ้าต้องการ) — พิมพ์รายงาน “Asset Loan Slip” เพื่อให้ผู้ยืมและผู้อนุมัติลงนาม
Draft → Confirm → Borrowed → Return → Returned

สายอื่นจาก Borrowed: Lost (ของหาย) · จากทุกสถานะที่ยังไม่คืน/หาย: Cancelled (ยกเลิก) · และจาก Cancelled กลับเป็น Draft ได้ด้วยปุ่ม Reset to Draft

การแจ้งเตือน (อัตโนมัติ)

  • Due Reminders — แจ้งเตือนใบยืมที่ครบกำหนดภายใน 1 วัน (ทุกวัน)
  • Overdue Alerts — แจ้งเตือนใบยืมที่เลยกำหนดคืนแล้ว (ทุกวัน)
  • Calibration Reminders — แจ้งเตือนอุปกรณ์ที่ถึงกำหนดสอบเทียบภายใน 7 วัน (ทุกวัน) ไปยังช่างผู้รับผิดชอบ

การแจ้งเตือนส่งผ่านบริการแจ้งเตือนกลาง notification.service (โมดูล od19_notification_multi_channel) ไปยังผู้ยืม/ผู้รับผิดชอบ

สิทธิ์และข้อจำกัดสำคัญ

  • ผู้ใช้ทั่วไป (base.group_user) อ่าน/สร้าง/แก้ไขได้ แต่ ลบไม่ได้
  • ผู้ดูแลระบบ (base.group_system) ลบได้ และมีกฎหลายบริษัท (ดูได้เฉพาะใบยืมของบริษัทตัวเอง)
  • ห้ามยืมอุปกรณ์ซ้ำ — อุปกรณ์ชิ้นเดียวกันจะยืมซ้ำไม่ได้หากยังมีใบยืมที่ยังใช้งาน (Draft/Borrowed) อยู่
  • จำนวนที่คืนต้องไม่เกินจำนวนที่ยืม และวันครบกำหนดต้องไม่ก่อนวันยืม
เกี่ยวกับการพิมพ์: รายงาน “Asset Loan Slip” (แบบฟอร์มใบยืม) มีช่องลงนามผู้ยืมและผู้อนุมัติ — พิมพ์จากปุ่ม Print ในใบยืมได้โดยตรง
เคล็ดลับ: ถ้าต้องการดูว่าอุปกรณ์ชิ้นไหนถูกยืมอยู่ ให้เปิดหน้าจออุปกรณ์แล้วดูปุ่ม Loans หรือใช้ตัวกรอง “Overdue” ในหน้าจอใบยืมเพื่อไล่ตามของที่เลยกำหนดคืน
