## 1. บทบาทผู้รับผิดชอบ (Responsibility Codes)

| รหัส | บทบาท | หน้าที่ในแผน |
|---|---|---|
| CEO | ผู้บริหารสูงสุด | อนุมัติ จัดสรรงบประมาณ ขับเคลื่อนวัฒนธรรม |
| ISO | ผู้ดูแลความปลอดภัยสารสนเทศ | กำกับ ประเมิน ตรวจสอบ ติดตามความคืบหน้า |
| IT | ผู้ดูแลระบบสารสนเทศ | ลงมือทางเทคนิค ติดตั้ง ปรับตั้ง สำรองข้อมูล |
| OWN | เจ้าของระบบ/ข้อมูล (เช่น หัวหน้าฝ่ายบัญชี) | กำหนดชั้นข้อมูล สิทธิ์ และอนุมัติการเข้าถึง |
| HR | ฝ่ายบุคคล | Onboarding/Offboarding อบรม พนักงาน |
| VEN | ผู้ให้บริการภายนอก/ผู้รับเหมา | ปฏิบัติตามข้อตกลงและนโยบาย |
| ALL | พนักงานทุกคน | ปฏิบัติตาม รายงานเหตุการณ์ |

> หมายเหตุ: องค์กรขนาดเล็กอาจให้ IT รับหลายบทบาทร่วมกับ ISO ได้ แต่ต้องมีผู้ทบทวนแยกจากผู้ปฏิบัติ (Segregation of Duties)

## 3. ระยะสั้น — Quick Wins (พ.ย. – ธ.ค. 2026)

| # | กิจกรรม | รายละเอียด | ผู้รับผิดชอบ | ผู้สนับสนุน | กำหนดเสร็จ | หลักฐานยืนยันผล |
|---|---|---|---|---|---|---|
| S1 | บังคับ MFA บัญชีสำคัญ | เปิด MFA สำหรับผู้ดูแลระบบ บัญชีการเงิน และการเข้าใช้จากภายนอก | IT | ISO | 2026-11-20 | รายงาน % บัญชีที่เปิด MFA |
| S2 | ทบทวนและลดสิทธิ์ผู้ดูแลระบบ | ถอดบัญชี admin ที่ไม่จำเป็น จำกัดจำนวนผู้ดูแล อนุมัติโดย CEO | IT | ISO, CEO | 2026-11-20 | ทะเบียนผู้ดูแลระบบที่อนุมัติแล้ว |
| S3 | ปิดช่องโหว่ Recon บน Odoo | ตั้ง `list_db=False`, `dbfilter`, ปิด Debug/Web Editor บน Production | IT | OWN | 2026-11-18 | ไฟล์ `odoo.conf` ฉบับปรับปรุง + ผลทดสอบ |
| S4 | เสริม Cloudflare | เปิด WAF + Rate Limiting + Turnstile + ซ่อน IP ต้นทาง + บังคับ HTTPS/HSTS | IT | ISO | 2026-11-25 | ภาพหน้าจอการตั้งค่า Cloudflare |
| S5 | ปิด RDP/SMB สู่อินเทอร์เน็ต | ปิดพอร์ตที่เปิดสู่ภายนอกทั้งหมด เข้าถึงผ่าน VPN/Bastion เท่านั้น | IT | ISO | 2026-11-22 | ผลสแกนพอร์ตจากภายนอก (ปิดครบ) |
| S6 | ตรวจสอบและกู้คืน Backup ได้จริง | ทดสอบ Restore จากข้อมูลสำรองจริง จัดทำ Immutable/Offline copy | IT | OWN | 2026-12-05 | บันทึกผลการทดสอบ Restore |
| S7 | ปรับปรุงแพตช์เร่งด่วน | อัปเดต OS/Odoo ที่มีช่องโหว่วิกฤตระดับ High | IT | ISO | 2026-12-10 | รายการแพตช์ที่ติดตั้งแล้ว |
| S8 | ประเมินช่องโหว่เบื้องต้น (Vulnerability Scan) | สแกนเซิร์ฟเวอร์และเว็บที่เปิดสาธารณะ จัดลำดับความเสี่ยง | IT | ISO | 2026-12-15 | รายงานผลสแกน + แผนแก้ไข |

## 4. ระยะกลาง — โครงสร้างป้องกันและตรวจจับ (ม.ค. – มี.ค. 2027)

| M10 | ทบทวนสิทธิ์การเข้าถึงรอบแรก | ตรวจสอบสิทธิ์ทุกบัญชีตามบทบาท | IT | OWN, หัวหน้าแผนก | 2027-03-31 | บันทึกผลทบทวนสิทธิ์ |

## 8. สมมติฐานและเงื่อนไข (Assumptions)

8.1 กำหนดเวลาสามารถปรับได้ตามความพร้อมของทรัพยากรและงบประมาณ โดยต้องได้รับอนุมัติจาก CEO

8.2 บางกิจกรรมต้องซื้อ/สมัครเครื่องมือเพิ่ม (เช่น EDR, SIEM, PAM, Pen Test) ต้องผ่านการอนุมัติงบประมาณ

8.3 การนำระบบขึ้น Production ทุกครั้ง ต้องสำรองข้อมูลก่อนและทดสอบบนสภาพแวดล้อมทดสอบ (ตามนโยบายข้อ 6.6)

8.4 การทำงานในรีโพนี้ต้องเป็นไปตาม [AGENTS.md](file:///c:/odoo-dev/odoo19/AGENTS.md) อย่างเคร่งครัด
