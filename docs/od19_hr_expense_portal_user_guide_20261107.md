# คู่มือการใช้งาน — ระบบเบิกค่าใช้จ่ายพนักงาน (HR Expense Portal)

- **โมดูล**: `od19_hr_expense_portal`
- **เวอร์ชัน**: 19.0.2.4.0
- **วันที่**: 2026-11-07
- **ขอบเขต**: การยื่นใบเบิกค่าใช้จ่ายผ่านพอร์ทัลพนักงาน (`/my/expenses`) และการพิมพ์ใบสรุป

> คู่มือนี้มีฉบับย่อในพอร์ทัลอยู่แล้วที่เมนู **คู่มือการใช้งาน** (`/my/expenses/help`)
> เพื่อให้พนักงานอ่านได้ทันทีโดยไม่ต้องออกจากระบบ

---

## 1. สำหรับพนักงาน (Employee)

### 1.1 เข้าสู่หน้าพอร์ทัล
1. เข้าสู่ระบบด้วยบัญชีพนักงานของตนเอง
2. ไปที่เมนู **My Account → ใบเบิกค่าใช้จ่าย** หรือเปิด URL `/my/expenses`
3. หน้าจอจะแสดง **ใบเบิกค่าใช้จ่ายของฉัน** เฉพาะรายการของตนเองเท่านั้น

> ระบบจำกัดสิทธิ์ด้วย Record Rule: พนักงานแต่ละคนเห็นได้เฉพาะใบเบิกที่ผูกกับ
> `employee_id` ของตนเอง ไม่สามารถเข้าถึงของผู้อื่นได้ (แม้จะทราบ URL ก็ตาม)

### 1.2 ยื่นใบเบิกใหม่
1. กดปุ่ม **ยื่นใบเบิก** (มุมซ้ายบนของหน้ารายการ)
2. กรอกข้อมูลให้ครบถ้วน

| ช่อง | คำอธิบาย |
|---|---|
| หมวดค่าใช้จ่าย | เลือกจากรายการที่เปิดให้เบิกได้ (`can_be_expensed`) |
| วันที่ | วันที่เกิดค่าใช้จ่าย (ค่าเริ่มต้น = วันนี้) |
| รายละเอียด | คำอธิบายรายการ |
| จำนวนเงิน | กรอกเมื่อเป็น **ค่าใช้จ่ายทั่วไป** |
| ระยะทาง (กม.) | กรอกเมื่อเป็น **ค่าเดินทางตามระยะทาง** |
| รถของฉัน | เลือกรถ (ถ้ามีการขึ้นทะเบียนไว้กับพนักงาน) |
| ต้นทาง / ปลายทาง | จุดเริ่ม–สิ้นสุดการเดินทาง |

3. ติ๊ก **ส่งอนุมัติทันที** หากต้องการส่งเข้าสายอนุมัติทันที (หรือปล่อยว่างเพื่อเก็บเป็นฉบับร่าง)
4. กดปุ่ม **ยื่นใบเบิก**

> **ค่าเดินทางตามระยะทาง**: ระบบคำนวณยอดเงินอัตโนมัติ = ระยะทาง (กม.) × อัตราต่อ กม.
> ของบริษัท (`od19_mileage_rate`) พนักงานไม่ต้องกรอกจำนวนเงินเอง

### 1.3 ระบบบันทึกร่างอัตโนมัติ (ไม่ต้องกลัวเน็ตหลุด)
- ข้อมูลที่กรอกในฟอร์มจะถูกบันทึกอัตโนมัติใน `localStorage` ของเบราว์เซอร์
- หากสัญญาณหลุดแล้วกลับมาใหม่ เพียงเปิดหน้าฟอร์มอีกครั้ง ข้อมูลเดิมจะกลับมา
- **ร่างจะถูกล้างอัตโนมัติ** เมื่อยื่นใบเบิกสำเร็จ
- ปุ่ม **ล้างร่างที่บันทึกไว้** ใช้ล้างข้อมูลที่ค้างอยู่ในเครื่องได้ทันที

### 1.4 คำนวณระยะทางจากแผนที่ (ถ้าผู้ดูแลเปิดใช้งาน)
- กรอก **ต้นทาง** และ **ปลายทาง** ก่อน
- กดปุ่ม **คำนวณระยะทางจากแผนที่** ระบบจะเติมระยะทางให้อัตโนมัติ
- พนักงานยังแก้ไขตัวเลขระยะทางได้ตามจริง
- หากไม่เปิดใช้งาน ปุ่มนี้จะไม่แสดง (ค่าเริ่มต้นของระบบคือปิด)

### 1.5 ติดตามสถานะการอนุมัติ
- เปิดรายการใบเบิกเพื่อดู **สถานะการอนุมัติ** ด้านขวา
- ลำดับการอนุมัติ: **หัวหน้างาน → ผู้จัดการ → การเงิน**
- สถานะที่แสดง: ฉบับร่าง, รออนุมัติ, อนุมัติแล้ว, บันทึกบัญชีแล้ว, กำลังจ่าย, จ่ายแล้ว, ถูกปฏิเสธ
- ใบเบิกที่เป็น **ฉบับร่าง** จะมีปุ่ม **ส่งอนุมัติ** ให้กดเมื่อพร้อม

## 2. สำหรับผู้ดูแลระบบ (Administrator)

### 2.1 เปิดใช้งานการคำนวณระยะทางจากแผนที่ (ค่าเริ่มต้น = ปิด)
ตั้งค่า System Parameters (Settings → Technical → System Parameters):

| Key | ค่า | ตัวอย่าง |
|---|---|---|
| `od19_hr_expense_portal.map_provider` | ผู้ให้บริการ | `ors` (OpenRouteService) |
| `od19_hr_expense_portal.map_api_key` | API Key | `<คีย์ของผู้ให้บริการ>` |

- ต้องตั้งค่า **ทั้งสองค่า** ปุ่มคำนวณระยะทางจึงจะแสดง
- **API Key ถูกเก็บและใช้เฉพาะฝั่งเซิร์ฟเวอร์** ไม่ถูกส่งไปยังเบราว์เซอร์ของพนักงาน

### 2.2 พิมพ์ใบสรุปการเบิกค่าใช้จ่าย
- เปิดเอกสารใบเบิก (`hr.expense`) ในระบบหลังบ้าน
- เลือก **Print → Expense Reimbursement Summary (ใบสรุปการเบิกค่าใช้จ่าย)**
- รายงานจะแสดง: ข้อมูลพนักงาน, ประเภทเอกสาร, ยอดเงิน, รายละเอียดค่าเดินทาง (ถ้ามี),
  จำนวนเงินเป็นตัวอักษร และช่องลงนาม (ผู้เบิก / ผู้อนุมัติ / ผู้จ่ายเงิน)
