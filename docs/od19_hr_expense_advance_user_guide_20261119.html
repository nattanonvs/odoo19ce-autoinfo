ระบบ HR Expense & Employee Advance — ฉบับผู้ใช้งาน

อธิบายขั้นตอนการยื่นใบเบิกค่าใช้จ่าย (Expense Reimbursement) และการเบิกเงินทดรองจ่าย (Employee Advance) ตั้งแต่ต้นจนจบ — ครอบคลุมการยื่น, การอนุมัติ, การจ่ายเงิน, การเคลียร์เงินทดรอง และการพิมพ์เอกสาร สำหรับพนักงานผู้ใช้งานทั่วไป

1เกี่ยวกับคู่มือนี้

คู่มือนี้อธิบายวิธีใช้งานระบบสองส่วนที่เกี่ยวเนื่องกัน ได้แก่ การเบิกค่าใช้จ่าย (คืนเงินให้พนักงานที่จ่ายไปก่อน) และ เงินทดรองจ่าย (เบิกเงินล่วงหน้าก่อนไปใช้จ่ายจริง) โดยเขียนจากพฤติกรรมจริงของโมดูลในระบบนี้

1.1 ความแตกต่างระหว่าง Expense กับ Advance

🧾 เบิกค่าใช้จ่าย (Expense)

พนักงาน จ่ายเงินไปก่อน แล้วนำหลักฐาน (ใบเสร็จ/ใบกำกับภาษี) มายื่นขอคืนเงิน ระบบบันทึกเป็นเจ้าหนี้พนักงาน แล้วจ่ายคืนให้เมื่ออนุมัติครบ

💰 เงินทดรองจ่าย (Advance)

พนักงาน ขอเงินล่วงหน้า ก่อนเดินทาง/ไปทำงาน ระบบจ่ายเงินจริงออกไปก่อน แล้วภายหลังจึงนำค่าใช้จ่ายมา เคลียร์ หักกลบ และคืนเงินส่วนที่เหลือ

เปรียบเทียบสั้น ๆ: Expense = ขอคืนเงินทีหลัง · Advance = ยืมเงินไปก่อน แล้วมาเคลียร์

1.2 โมดูลที่เกี่ยวข้อง

โมดูลหน้าที่หลักบทบาทที่เห็นผล
od19_hr_expense_enhancedฟีเจอร์ค่าใช้จ่ายขั้นสูง — เบี้ยเลี้ยง ม.42(3), ค่าเดินทางตามระยะทาง, ใบรับรองแทนใบเสร็จ, สถานะเงินสด, ภาษีหัก ณ ที่จ่าย, สมุดรถพนักงาน, ส่งออก XLSXพนักงาน / บัญชี
od19_hr_expense_thaiสายอนุมัติ 3 ชั้น, วิธีจ่ายคืน (เงินสด/โอน/เช็ค), ปุ่มจ่ายคืนพนักงานจริงพนักงาน / ผู้อนุมัติ
od19_hr_expense_portalหน้า Portal พนักงาน (/my/expenses), วิซาร์ดยื่นใบเบิกด่วน, มุมมอง Kanban “ใบเบิกของฉัน”, รายงานใบสรุปพนักงาน
od19_hr_advanceใบเบิกเงินทดรองจ่าย: อนุมัติ 2 ชั้น, จ่ายเงินจริง, เคลียร์และคืนเงินส่วนที่เหลือพนักงาน / บัญชี

1.3 บทบาทและสิทธิ์โดยสรุป

บทบาทสิ่งที่ทำได้
พนักงาน (Employee)ยื่นใบเบิกค่าใช้จ่าย, ยื่นใบเบิกเงินทดรอง, ติดตามสถานะของตนเอง
หัวหน้าแผนก (Department Manager)อนุมัติชั้นที่ 1 ของทั้ง Expense และ Advance (มอบหมายต่อได้)
ฝ่ายบัญชี (Account Manager)อนุมัติชั้นที่ 2, บันทึกบัญชี, จ่ายเงินทดรอง, จ่ายคืนพนักงาน, เคลียร์เงินทดรอง, ภาษีหัก ณ ที่จ่าย
CEO (Expense CEO Approver)อนุมัติชั้นที่ 3 ของค่าใช้จ่าย

2เริ่มต้นใช้งานและภาพรวมเมนู

ทุกอย่างเริ่มจากแอปหลัก Expenses ในแถบเมนูด้านบน ระบบนี้เพิ่มเมนูให้ใช้งานดังนี้

เมนูอยู่ใต้ใช้ทำอะไรใครเห็น
ยื่นใบเบิกค่าใช้จ่ายExpensesเปิดวิซาร์ดยื่นใบเบิกแบบเร็ว (4 ขั้น)พนักงานทุกคน
ใบเบิกของฉันExpensesมุมมอง Kanban/ลิสต์ เฉพาะใบเบิกของตนเองพนักงานทุกคน
Employee Advances เงินทดรองExpensesสร้าง/ติดตามใบเบิกเงินทดรองจ่ายพนักงานทุกคน
Expenses (เมนูเดิมของ Odoo)—รายการใบเบิกทั้งหมด (สำหรับผู้มีสิทธิ์/หัวหน้า/บัญชี)ตามสิทธิ์
ทางเข้าแบบเร็ว: พนักงานยังเข้าใช้งานผ่านพอร์ทัลได้ที่เมนูบัญชีของฉัน → ใบเบิกค่าใช้จ่าย หรือเปิด URL /my/expenses โดยตรงได้ทันที

2.1 ก่อนเริ่ม — เตรียมข้อมูลให้พร้อม

  • บัญชีผู้ใช้ต้อง ผูกกับข้อมูลพนักงาน (Employee) แล้ว มิฉะนั้นระบบจะไม่รู้ว่าใครเป็นผู้เบิก
  • ถ้าเป็นการเดินทางด้วยรถยนต์ ควรขึ้นทะเบียน รถของฉัน ไว้ที่เมนู Expenses → My Vehicles ล่วงหน้า
  • เตรียม หลักฐานการใช้จ่าย (ใบเสร็จ/ใบกำกับภาษี) ให้พร้อมก่อนบันทึก

3การเบิกค่าใช้จ่าย (Expense)

ระบบมี 3 ช่องทาง ในการยื่นใบเบิก เลือกใช้ตามความสะดวก ผลลัพธ์ปลายทางเหมือนกัน (สร้างเอกสาร hr.expense)

3.1 เปรียบเทียบช่องทางยื่นใบเบิก

1) วิซาร์ดด่วน

เมนู Expenses → ยื่นใบเบิกค่าใช้จ่าย กรอกเร็ว 4 ขั้น เหมาะกับการเบิกทั่วไป/ค่าเดินทาง

2) ใบเบิกของฉัน

เมนู Expenses → ใบเบิกของฉัน ดูรายการของตัวเองแบบ Kanban แยกตามสถานะ

3) พอร์ทัล

เปิด /my/expenses ใช้ง่ายบนมือถือ มีบันทึกร่างอัตโนมัติ

3.2 ยื่นใบเบิกผ่านวิซาร์ด “ยื่นใบเบิกค่าใช้จ่าย”

  1. เปิดวิซาร์ด — ไปที่เมนู Expenses → ยื่นใบเบิกค่าใช้จ่าย หน้าต่างกรอกข้อมูลจะเปิดขึ้น
  2. ขั้นที่ 1 — ข้อมูลเบื้องต้น เลือก หมวดค่าใช้จ่าย, พนักงาน (ค่าเริ่มต้นคือตัวเอง), วันที่ เกิดค่าใช้จ่าย และกรอก รายละเอียด
  3. ขั้นที่ 2 — จำนวนเงิน หากเป็นค่าใช้จ่ายทั่วไปให้กรอก จำนวนเงิน; หากเป็นค่าเดินทางตามระยะทาง ระบบจะเปลี่ยนไปกรอก ระยะทาง (กม.) แทน แล้วคิดยอดให้อัตโนมัติ
  4. ขั้นที่ 3 — รายละเอียดการเดินทาง (แสดงเฉพาะค่าเดินทาง) กรอก ต้นทาง และ ปลายทาง
  5. ขั้นที่ 4 — การส่ง ติ๊ก ส่งอนุมัติทันที หากพร้อมส่งเข้าสายอนุมัติ หรือปล่อยว่างเพื่อเก็บเป็นฉบับร่างก่อน
  6. ยืนยัน กดปุ่ม ยื่นใบเบิก ระบบจะสร้างเอกสารและเปิดหน้าใบเบิกให้ทันที

ตารางฟิลด์ในวิซาร์ด

ฟิลด์คำอธิบายบังคับ
หมวดค่าใช้จ่ายเลือกจากรายการที่เปิดให้เบิกได้ (แฟล็ก Can be expensed)ใช่
พนักงานผู้เบิก (ค่าเริ่มต้น = พนักงานที่ผูกกับบัญชีผู้ใช้)ใช่
วันที่วันที่เกิดค่าใช้จ่าย (ค่าเริ่มต้น = วันนี้)ใช่
รายละเอียดคำอธิบายสั้นของรายการ—
จำนวนเงินกรอกเมื่อเป็นค่าใช้จ่ายทั่วไปตามประเภท
ระยะทาง (กม.) / รถของฉัน / อัตราต่อ กม.กรอกเมื่อเป็น ค่าเดินทางตามระยะทาง — ยอดรวมคำนวณให้อัตโนมัติตามประเภท
ต้นทาง / ปลายทางจุดเริ่ม–สิ้นสุดการเดินทาง (เฉพาะค่าเดินทาง)—
ส่งอนุมัติทันทีติ๊ก = ส่งเข้าสายอนุมัติทันที / ไม่ติ๊ก = เก็บเป็นฉบับร่าง—

3.3 ยื่นใบเบิกผ่านพอร์ทัล (สำหรับพนักงาน)

เปิด URL /my/expenses หรือเข้าจากเมนูบัญชีของฉัน

  1. เข้าสู่หน้าพอร์ทัล ระบบแสดงเฉพาะใบเบิกของตนเอง (ถูกจำกัดด้วย Record Rule — เห็นได้เฉพาะของตัวเอง แม้รู้ URL ของผู้อื่นก็เปิดไม่ได้)
  2. กดปุ่ม “ยื่นใบเบิก” ที่มุมซ้ายบนของหน้ารายการ
  3. กรอกแบบฟอร์ม เลือกหมวดค่าใช้จ่าย, วันที่, รายละเอียด และจำนวนเงิน (หรือระยะทางหากเป็นค่าเดินทาง)
  4. ส่งอนุมัติ ติ๊ก “ส่งอนุมัติทันที” แล้วกด ยื่นใบเบิก
  5. ติดตามสถานะ เปิดรายการเพื่อดูสถานะการอนุมัติด้านขวา
บันทึกร่างอัตโนมัติ: ข้อมูลที่กรอกในฟอร์มพอร์ทัลจะถูกเก็บไว้ในเบราว์เซอร์อัตโนมัติ หากอินเทอร์เน็ตหลุดแล้วกลับมา เพียงเปิดหน้าเดิมอีกครั้งข้อมูลจะกลับมาเอง ร่างจะถูกล้างเมื่อยื่นสำเร็จ และมีปุ่ม “ล้างร่างที่บันทึกไว้” หากต้องการเคลียร์เอง
คำนวณระยะทางจากแผนที่ (ถ้าผู้ดูแลเปิดใช้): กรอกต้นทาง–ปลายทาง แล้วกด “คำนวณระยะทางจากแผนที่” ระบบจะเติมระยะทางให้ ยังแก้ไขตัวเลขเองได้ตามจริง ค่าเริ่มต้นของระบบคือ ปิด

3.4 ประเภทค่าใช้จ่ายพิเศษ

นอกจากค่าใช้จ่ายทั่วไป ระบบรองรับการเบิกแบบพิเศษ เพิ่มเติมได้ในหน้าเอกสารใบเบิก (แถบหลังบ้าน)

ก) ค่าเดินทางตามระยะทาง (Mileage)

  • เลือกหมวด “ค่าเดินทางตามระยะทาง / Mileage” แล้วกรอก ระยะทาง (กม.), เลือก รถของฉัน, ต้นทาง, ปลายทาง, วันที่เดินทาง
  • ยอดเงินคำนวณอัตโนมัติ = ระยะทาง × อัตราต่อ กม. ของบริษัท (ตั้งค่าโดยผู้ดูแล) พนักงานไม่ต้องกรอกจำนวนเงินเอง
  • ระบบบันทึกประเภทยานพาหนะและป้ายทะเบียน ณ เวลาที่เบิกไว้ด้วย (เป็นข้อมูลอ้างอิงแบบ snapshot)

ข) เบี้ยเลี้ยงตาม ม.42(3) (Per Diem)

ฟิลด์คำอธิบาย
เบี้ยเลี้ยงติ๊กเพื่อระบุว่ารายการนี้เป็นเบี้ยเลี้ยงตามมาตรา 42(3)
พื้นที่ในประเทศ / ต่างประเทศ (มีวงเงินต่อวันคนละอัตรา)
จำนวนวันจำนวนวันที่ได้รับเบี้ยเลี้ยง
วงเงินมาตรฐานต่อวันแสดงอัตโนมัติจากนโยบายบริษัท (อ่านเท่านั้น)
วงเงินเบี้ยเลี้ยง= วงเงินต่อวัน × จำนวนวัน (อ่านเท่านั้น)
เกินวงเงินระบบติ๊กให้อัตโนมัติเมื่อยอดเกินวงเงิน
เหตุผลที่เกินวงเงินบังคับกรอก เมื่อเกินวงเงิน

ค) ประเภทเอกสารประกอบและภาษีซื้อ

ประเภทเอกสารความหมายหมายเหตุ
ใบกำกับภาษี (Tax Invoice)เอกสารที่มี VAT — เครดิตภาษีซื้อได้ใช้ทั่วไป
ใบเสร็จรับเงิน (Receipt)เอกสารรับเงินทั่วไป—
ใบรับรองแทนใบเสร็จรับเงิน (Payment Certificate)ใช้เมื่อไม่มีใบเสร็จ — เป็นเอกสารรับรองการจ่ายเงินต้องกรอก เลขที่ใบรับรอง; เครดิตภาษีซื้อ = ไม่ได้ และมีปุ่มพิมพ์ใบรับรองโดยเฉพาะ

3.5 สายการอนุมัติค่าใช้จ่าย (3 ชั้น ตามลำดับ)

ใบเบิกค่าใช้จ่ายต้องผ่านการอนุมัติเรียงตามลำดับ ผู้อนุมัติสามารถ “มอบหมายต่อ (Forward)” ให้ผู้ใช้อื่นในกลุ่มเดียวกันได้

1. หัวหน้าแผนก→ 2. ฝ่ายบัญชี→ 3. CEO→ อนุมัติ / บันทึกบัญชี / จ่ายคืน
ชั้นผู้อนุมัติ (กลุ่ม)ผลเมื่อผ่าน
ชั้นที่ 1หัวหน้าแผนก (HR Expense Manager)ส่งต่อไปยังชั้นที่ 2
ชั้นที่ 2ฝ่ายบัญชี (Account Manager)ส่งต่อไปยังชั้นที่ 3
ชั้นที่ 3CEO (Expense CEO Approver)ครบทุกชั้น → อนุมัติแล้ว (Approved)
ข้อยกเว้นตามวงเงิน: หากยอดใบเบิกเกินเกณฑ์ที่กำหนด (ค่าเริ่มต้น 5,000 บาท ปรับได้โดยผู้ดูแล) ระบบจะตั้งค่าธง Require Second Approval เป็น “ต้องอนุมัติเพิ่ม” โดยอัตโนมัติ

3.6 ติดตามสถานะการอนุมัติ

เปิดรายการใบเบิกของตนเอง จะเห็นแถบสถานะด้านบน และ timeline การอนุมัติด้านขวา (แสดงว่าใครอนุมัติแล้ว/กำลังรอใคร)

ฉบับร่าง→ ส่งอนุมัติ→ อนุมัติแล้ว→ บันทึกบัญชี→ กำลังจ่าย→ จ่ายแล้ว

สถานะ “ถูกปฏิเสธ (Refused)” จะแสดงเมื่อผู้อนุมัติขั้นใดขั้นหนึ่งปฏิเสธ

3.7 รายงานและเอกสารที่พิมพ์ได้

4เงินทดรองจ่ายพนักงาน (Advance)

ใช้เมื่อพนักงานต้องใช้เงินล่วงหน้า (เช่น ไปต่างจังหวัด ประสานงานภาคสนาม) — ระบบจะ จ่ายเงินจริง ให้ก่อน แล้วภายหลังนำค่าใช้จ่ายมาเคลียร์

4.1 เข้าเมนู

ไปที่ Expenses → Employee Advances จะเห็นรายการใบเบิกเงินทดรองทั้งหมด (ใช้ตัวกรอง My Advances เพื่อดูเฉพาะของตนเอง)

  3. บันทึก เอกสารจะได้เลขที่อัตโนมัติรูปแบบ HRADV/ปี/เลขรัน (เช่น HRADV/2026/00001)
  4. ยื่นอนุมัติ กดปุ่ม Submit for Approval เพื่อเข้าสายอนุมัติ 2 ชั้น

ใบเบิกที่ จ่ายเงินแล้ว หรือ เคลียร์ครบ จะ ยกเลิกไม่ได้ และระบบจะไม่ยอมให้ลบ — ต้องดำเนินการเคลียร์ให้ครบแทน

4.5 การเคลียร์เงินทดรอง

เมื่อใช้เงินทดรองไปแล้ว พนักงานนำ ค่าใช้จ่าย (Expense) ที่เกิดขึ้นจริงมาเคลียร์หักกลบ และคืนเงินส่วนที่เหลือกลับบริษัท (ขั้นตอนนี้ทำโดย ฝ่ายบัญชี / HR Manager)

  1. เปิดใบเบิกเงินทดรองที่สถานะ “จ่ายเงินแล้ว” แล้วกดปุ่ม Clear
  2. เลือกค่าใช้จ่ายที่จะนำมาเคลียร์ ในฟิลด์ Cleared Expenses (เลือกได้เฉพาะค่าใช้จ่ายของพนักงานคนเดียวกันและยังไม่เคยถูกเคลียร์)
  3. กรอกเงินคืน (ถ้ามี) ในฟิลด์ Returned Amount และเลือก สมุดรับเงินคืน (บังคับเลือกเมื่อมียอดคืน)
  4. ระบุวันที่เคลียร์ ในฟิลด์ Clearing Date
  5. ยืนยัน ระบบสร้างรายการบัญชีหักกลบและ reconcile ให้อัตโนมัติ
กฎการเคลียร์

• ต้องเคลียร์เฉพาะใบเบิกที่ จ่ายเงินแล้ว
• ต้องมีอย่างน้อย 1 อย่าง: ค่าใช้จ่าย หรือ เงินคืน
• ยอดเคลียร์รวม (ค่าใช้จ่าย+เงินคืน) ห้ามเกินยอดคงเหลือ
• เงินคืนต้องไม่ติดลบ และต้องเลือกสมุดบัญชี

การเคลียร์บางส่วน

เคลียร์ไม่ครบได้ — ใบเบิกจะคงสถานะ “จ่ายเงินแล้ว” และเคลียร์เพิ่มได้ภายหลัง เมื่อยอดคงเหลือเหลือ ≈ 0 ระบบจะเปลี่ยนเป็น เคลียร์ครบ (Cleared) ให้เอง

ความเชื่อมโยงกับค่าใช้จ่าย (Expense)

เมื่อเคลียร์แล้ว ระบบจะบันทึกว่าค่าใช้จ่ายรายการนั้นถูกนำไปใช้กับใบเบิกเงินทดรองใบใด (ค่าใช้จ่าย 1 รายการเคลียร์กับเงินทดรองได้เพียงใบเดียว) และจะปรากฏในแท็บ Cleared Expenses ของใบเบิกเงินทดรองนั้น

5ภาคผนวก ก — คู่มือผู้อนุมัติ

ผู้อนุมัติจะเข้ามุมมองที่หน้ารายการใบเบิก (ทั้ง Expense และ Employee Advances) แล้วเปิดเอกสารที่ต้องการตรวจ

5.1 หัวหน้าแผนก (ชั้นที่ 1)

  • ตรวจความถูกต้องของรายการ หลักฐาน และวงเงิน
  • กด Approve ที่แท็บการอนุมัติเพื่อผ่านไปชั้นถัดไป หรือ Refuse เพื่อปฏิเสธ (พร้อมใส่เหตุผล)
  • หากติดธุระ ใช้ปุ่ม Forward เพื่อมอบหมายให้ผู้อนุมัติคนอื่นในกลุ่มเดียวกัน

5.2 ฝ่ายบัญชี (ชั้นที่ 2 ของ Expense · ชั้นที่ 2 ของ Advance)

  • อนุมัติผ่านชั้นบัญชี
  • ตรวจบัญชี/หมวดค่าใช้จ่ายที่บันทึก และความถูกต้องของภาษี (ดูภาคผนวก ข)

5.3 CEO (ชั้นที่ 3 ของ Expense)

  • อนุมัติชั้นสุดท้ายของค่าใช้จ่าย เมื่อครบทุกชั้นแล้วเอกสารจะเป็น “อนุมัติแล้ว”
ระบบใช้กลไกอนุมัติแบบมีลำดับ (Sequential) — ต้องอนุมัติชั้นก่อนหน้าให้ครบก่อน จึงจะถึงคิวของชั้นถัดไป

6ภาคผนวก ข — คู่มือฝ่ายบัญชี

6.1 การจ่ายเงินทดรอง (Pay Advance)

  • เปิดใบเบิกเงินทดรองสถานะ อนุมัติแล้ว แล้วกด Pay Advance
  • ระบบสร้างรายการจ่ายเงิน (outbound payment) ให้พนักงาน: เดบิตบัญชีลูกหนี้พนักงาน / เครดิตเงินสด–ธนาคาร
  • สถานะเปลี่ยนเป็น จ่ายเงินแล้ว พร้อมบันทึกเลขที่เอกสารจ่ายและวันที่จ่ายไว้ในฟอร์ม

6.2 การเคลียร์เงินทดรอง

ดูรายละเอียดขั้นตอนในหัวข้อ 4.5 — เมื่อเคลียร์ ระบบจะสร้างรายการบัญชี: เดบิตบัญชีค่าใช้จ่าย (ตามค่าใช้จ่ายที่เลือก), เดบิตเงินสด/ธนาคาร (เงินคืน — ถ้ามี), เครดิตบัญชีลูกหนี้พนักงาน และทำ reconciliation ให้อัตโนมัติ

6.3 การจ่ายคืนพนักงาน (Reimburse Employee)

สำหรับใบเบิกค่าใช้จ่ายที่พนักงานจ่ายเอง (โหมด own_account) เมื่อบันทึกบัญชีแล้ว จะมีปุ่ม Reimburse Employee ให้กดเพื่อสร้างรายการจ่ายคืนจริง

วิธีจ่ายคืนสมุดที่ระบบเลือก
เงินสด (Cash)สมุดประเภทเงินสด
โอนธนาคาร (Bank Transfer)สมุดประเภทธนาคาร
เช็ค (Cheque)สมุดประเภทธนาคาร

ระบบจะ post รายการจ่ายและ reconcile กับเจ้าหนี้พนักงานให้อัตโนมัติ พร้อมบันทึกวันที่จ่ายคืน

6.4 ภาษีหัก ณ ที่จ่าย (WHT) บนรายการจ่ายค่าใช้จ่าย

บนรายการจ่ายค่าใช้จ่าย (account.payment) สามารถระบุประเภทภาษีหักได้ (1% / 2% / 3% / 5%) พร้อมมูลค่าคิดภาษีและบัญชีที่เกี่ยวข้อง ระบบคำนวณยอดภาษีหักให้อัตโนมัติ

6.5 สถานะเงินสดของค่าใช้จ่าย (เบิกเงินสดไปใช้)

ค่าใช้จ่ายที่จ่ายเป็นเงินสดมีสถานะเงินสดคู่ขนานให้ติดตาม — ไม่ใช่ทุกใบจะต้องใช้ครบทุกขั้น:

ยังไม่ได้รับเงิน→ ได้รับเงินแล้ว→ ใช้เงินแล้ว→ คืนเงินแล้ว

ปุ่มที่เกี่ยวข้อง: Receive Cash, Use Cash, Return Cash (เปิดวิซาร์ดคืนเงิน พร้อมสร้างรายการบัญชีได้) และ Reset Cash (สำหรับผู้ดูแล)

หากยังเป็น “ฉบับร่าง” แก้ไขได้เลย หากส่งอนุมัติไปแล้ว การแก้ไขขึ้นกับสถานะและสิทธิ์ — โดยทั่วไปให้ติดต่อผู้อนุมัติหรือฝ่ายบัญชีเพื่อขอปฏิเสธแล้วยื่นใหม่

ค่าเดินทางตามระยะทาง ต้องกรอกจำนวนเงินเองไหม?

ไม่ต้อง ระบบคำนวณจาก ระยะทาง × อัตราต่อ กม. ของบริษัทให้อัตโนมัติ

เบี้ยเลี้ยงเกินวงเงิน ทำได้ไหม?

ทำได้ แต่ระบบบังคับให้กรอก “เหตุผลที่เกินวงเงิน” และจะแสดงธงว่าเกินวงเงินเพื่อให้ผู้อนุมัติพิจารณา

ใบเบิกเงินทดรอง ใครเป็นคนเคลียร์?

ขั้นตอนเคลียร์ทำโดย ฝ่ายบัญชี หรือ HR Manager พนักงานมีหน้าที่นำค่าใช้จ่ายและเงินส่วนที่เหลือมาส่งมอบ

เคลียร์เงินทดรองได้บางส่วนไหม?

ได้ ใบเบิกจะคงสถานะ “จ่ายเงินแล้ว” และเคลียร์เพิ่มได้ภายหลัง จนกว่ายอดคงเหลือจะเหลือศูนย์ จึงจะเปลี่ยนเป็น “เคลียร์ครบ”

ยอดหน้า Portal ไม่ขึ้น รายการหาย?

ตรวจว่าบัญชีผู้ใช้ผูกกับข้อมูลพนักงานและมีสิทธิ์เข้าถึงรายการนั้น หรือทำ Hard Refresh (Ctrl+Shift+R) ล้างแคชเบราว์เซอร์ก่อน
