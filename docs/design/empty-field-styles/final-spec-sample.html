OD19 — ตัวอย่างสุดท้าย: ช่องว่าง = Liquid Glass · ช่องมีข้อมูล = ดั้งเดิมของระบบ

แสดงบนพื้นฟอร์ม "สีขาว" เหมือนหน้าจริง · ฝั่งช่องมีข้อมูลใช้สไตล์ดั้งเดิมของ Odoo 19 (เส้นใต้เส้นเดียว #ccc พื้นใส) ไม่ปรุงแต่งเพิ่ม

1

สังเกต: ช่องว่างอ่านออกเป็น "ช่องให้กรอก" ด้วยไฮไลต์ขาวด้านบน + เงานุ่ม ส่วนช่องที่มีข้อมูลยังเรียบเหมือนเดิม → ภาพรวมยังสะอาด ไม่รกตา
2

เทียบตรง ๆ ทีละช่อง

ซ้าย = ช่องว่าง (Liquid Glass) · ขวา = ช่องมีข้อมูล (ดั้งเดิมของระบบ)

Empty / Entry field → Liquid Glass
ชื่อลูกค้า
แผ่นกระจกโปร่งแสง เบลอฉากหลัง + ขอบไฮไลต์ขาวด้านบน + เงาล่างนุ่ม
Filled field → ดั้งเดิมของระบบ
ชื่อลูกค้า
เส้นใต้เส้นเดียวสี #ccc · พื้นหลังใส · ไม่มีขอบ/เงาเพิ่ม (สไตล์ Odoo เดิม)
3

ขยาย (zoom) ให้เห็นรายละเอียดของกระจก

ทำการ์ดนี้เพื่อให้เห็นไฮไลต์/เงาชัด ๆ · ในการใช้งานจริงขนาดจะเท่าปกติ (ดูภาพที่ 1)

Empty → Liquid Glass
Filled → ดั้งเดิม
Empty (บนพื้นลายสี) — เห็น "ความเป็นกระจก" ชัดขึ้น
Filled (บนพื้นลายสี) — ยังเป็นเส้นใต้เรียบเหมือนเดิม
4

CSS ที่จะใช้จริง (สรุป)

Empty ได้ glass · Filled ไม่ถูกแตะเลย (คงสไตล์ดั้งเดิม)

/* Empty field (แก้ไขอยู่) → Liquid Glass */

    backdrop-filter: blur(10px) saturate(150%);

หมายเหตุ: ตัวปัจจุบันในโมดูลยังมีกฎเหมารวมที่ให้ "ทุกช่อง" พื้นเทาอ่อน (#f8f9fb) — ถ้าตกลงตามตัวอย่างนี้ จะปรับให้กฎนั้นไม่มีผลกับช่องที่มีข้อมูล เพื่อให้ช่อง filled กลับไปเป็นดั้งเดิมจริง
