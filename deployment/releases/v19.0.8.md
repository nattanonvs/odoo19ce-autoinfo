## Migration / Upgrade

- ติดตั้งใหม่: `-i od19_iso_dar`
- อัปเดต: `-u od19_website,od19_ui_defaults,od19_iso_dar`
- ไม่มี migration สคริปต์; ไม่แตะข้อมูลเดิม

```bash
python odoo-bin -c <odoo.conf> -d <DB> \
  -u od19_website,od19_ui_defaults,od19_iso_dar \
  --stop-after-init
```

## Rollback

- ถอน `od19_iso_dar` → โมดูลอื่นยังทำงานปกติ (additive)
- `od19_website` / `od19_ui_defaults` ไม่ได้ขยับ `version` — ถอยกลับรุ่นก่อนได้โดยไม่มีการลบข้อมูล

```bash
git checkout v19.0.7
git submodule update --init --recursive
```
