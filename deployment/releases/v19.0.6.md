## สคริปต์ / Deployment

- `run-tests.ps1` — แก้ 2 จุด: (1) ลบ UTF-8 BOM ซ้ำในหัวไฟล์สคริปต์ (2) ดึง `--data-dir` จาก `odoo.conf` เป็นค่าเริ่มต้น เพื่อกันปัญหา asset 404 จาก filestore ไม่ตรงกับ DB หลัก

## Migration / Upgrade

- **ไม่มี data migration** — รุ่นนี้ไม่มีการเปลี่ยน schema ที่ต้อง migrate ข้อมูล (ยกเว้นการสร้างดัชนี `pg_trgm` ของ `od19_document_hub` ซึ่งทำใน pre-init hook)
- โมดูลที่อัปเดต/เพิ่ม อัปเกรดด้วย `-u`:

```bash
python odoo-bin -c <odoo.conf> -d <DB> \
  -u od19_website,od19_ui_defaults,od19_thai_font_support,od19_user_guide_tours,od19_document_hub,od19_field_hints \
  --stop-after-init
```
