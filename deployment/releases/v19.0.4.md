## Migration / Upgrade

- **ไม่มี data migration** — รุ่นนี้ไม่มีการเปลี่ยน schema ที่ต้อง migrate ข้อมูล
- โมดูลใหม่ 1 ตัว ต้องติดตั้งด้วย `-i` (ถ้ายังไม่มีในฐานข้อมูล):

```bash
python odoo-bin -c <odoo.conf> -d <DB> \
  -i od19_offline_draft \
  --stop-after-init
```

- โมดูลที่อัปเดต อัปเกรดด้วย `-u`:

```bash
python odoo-bin -c <odoo.conf> -d <DB> \
  -u od19_ai_assistant \
  --stop-after-init
```
