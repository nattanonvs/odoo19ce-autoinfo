## Migration / Upgrade

- **ไม่มี data migration** — รุ่นนี้ไม่มีการเปลี่ยน schema ที่ต้อง migrate ข้อมูล
- โมดูลใหม่ 2 ตัว ต้องติดตั้งด้วย `-i` (ถ้ายังไม่มีในฐานข้อมูล):

```bash
python odoo-bin -c <odoo.conf> -d <DB> \
  -i od19_ai_assistant,od19_hr_expense_portal \
  --stop-after-init
```

- โมดูลที่อัปเดต อัปเกรดด้วย `-u`:

```bash
python odoo-bin -c <odoo.conf> -d <DB> \
  -u od19_accounting_payment_voucher_reports,od19_approval_center,od19_billing_request,od19_hr_expense_enhanced,od19_hr_expense_thai,od19_purchase_procurement_core,od19_role_catalog,od19_ui_defaults,od19_user_guide_tours,od19_web_navigation,od19_dashboard,od19_accounting_reporting,od19_after_sales_reporting,od19_hr_attendance_zkteco,od19_inventory_reporting \
  --stop-after-init
```
